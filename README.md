# Centro-De-Capacitacion-Ultra-Automatizado
Centro de Capacitación Ultra-Automatizado: Fábrica de cursos bajo demanda impulsada por IA. Este proyecto implementa un sistema de Generación Aumentada por Recuperación (RAG) y Agentes autónomos de LangChain para transformar las necesidades de capacitación del cliente en cursos completos, personalizados y listos para usar en minutos u horas.
